# Young Builders Club

Static site, ready for GitHub Pages.

1. Push the contents of this folder to the root of a repo.
2. Settings → Pages → Source: Deploy from branch → `main` / `(root)`.
3. Live at `https://<user>.github.io/<repo>/`.

All paths are relative, so it works from a project subpath. `.nojekyll` stops GitHub from skipping files.
